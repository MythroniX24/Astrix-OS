# Astrix OS - core package set for the minimal Debian userspace.
#
# Rules:
#  - No desktop environment (no task-*-desktop, no GNOME/KDE/XFCE/MATE).
#  - Everything here must be justifiable for a phone: boot, graphics, input,
#    audio, networking, power, and the core userland.
#  - The Wayland session must work with nothing else started.
#
# Developer tooling lives in config/packages-dev.txt so that the shipping
# image stays small; a "full" build installs both.
